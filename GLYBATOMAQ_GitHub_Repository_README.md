# GLYBATOMAQ™ — CTQW–MQWalk–MBHA molecular-graph audit framework

**Research and reproducibility repository | Draft v0.1.0 | GLIPR1-focused computational medicinal chemistry**

This repository contains the GLYBATOMAQ™ manuscript, supporting figures, four source HSX molecular records, archived docking-score tables, independently runnable numerical checks, and prototype IBM Qiskit / Rigetti pyQuil circuit examples. It is designed as a reviewable research code-and-data deposit; publication or public deposition has **not** been performed by this package creator.

## Quick start

Requirements: Python 3.13 recommended (the archived checks used Python 3.13.5), with NumPy, SciPy and RDKit.

```bash
python -m venv .venv
source .venv/bin/activate                # Windows: .venv\Scripts\activate
python -m pip install -r requirements-core.txt
python code/reproduce_core.py
python tests/test_core.py
python code/portable_gate_consistency.py
python code/mbha_fixed_library.py
python source_table_audit/audit_reproduce.py
python code/chemistry_identity_report.py
```

`computed/` includes frozen example outputs. Results are generated by classical CPU calculations from the distributed files; the scripts do **not** perform molecular docking, molecular dynamics, DFT, QMC or QPU hardware runs. No credentials or network access are required for the core tests.

## What the computations do

1. Parse four original **source-defined** ligand bond tables with RDKit sanitization deliberately disabled; record the number of heavy atoms and a source-to-label crosswalk.
2. Build one undirected adjacency matrix per candidate, its real symmetric graph Laplacian and continuous-time quantum-walk (CTQW) propagator.
3. Compare coherent return mass, classical heat diffusion and a symmetric nonlocal teleport-**edge** coupling (alpha = 0.18).
4. Reproduce a source-table four-candidate weighted fusion score and six deterministic leave-one-component-out ablations.
5. Demonstrate a seeded, fixed-candidate-library MBHA search heuristic without chemical structure creation or receptor redocking.
6. Provide two-qubit portable *software* circuit examples for IBM Qiskit and Rigetti pyQuil, not full 92–101-heavy-atom Hamiltonian hardware executions.

## Chemical identity status

The MOL2 records are **not fully chemically certified**. Several source bonds or aromaticity/valence states require atom-level reconstruction and stereochemical review; the data are useful for a source-bond **mathematical graph demonstration**. The source-file mapping, established by coordinates, is:

| Designation | Source MOL2 file | Source PDB | Heavy atoms |
|---|---|---|---:|
| HSX-cons2 | `GLYBATOMAQ-HSX-cons1 (1).mol2` | `GLYBATOMAQ-HSX-cons2.pdb` | 92 |
| HSX-cons1 | `GLYBATOMAQ-HSX-cons1 (2).mol2` | `GLYBATOMAQ-HSX-cons1.pdb` | 94 |
| HSX-cons3 | `GLYBATOMAQ-HSX-cons3.mol2` | `GLYBATOMAQ-HSX-cons3.pdb` | 91 |

Preferred IUPAC names in the source archive are *investigator-assigned labels*, **not independently certified names**, and must not override observed atom and bond records.

## Docking-target and evidence separation

**PDB 2GLI is a GLI–DNA complex, NOT GLIPR1.** Its associated iGEMDOCK records are confined to `data/archived_docking_2GLI/`. GLIPR1 crystal-structure context is **3Q2U/3Q2R**. Historical DockThor 3Q2R values are in `source_table_audit/data/source_dockthor_3Q2R.csv`, marked as *source-reported*; no raw docking project has been independently rerun or audited here. Scores from different receptors or scoring packages cannot be interpreted as one common binding-affinity scale.

The geometric *black-hole-inspired* landscape is an optimization metaphor; no physical black-hole coupling or universal geometry-to-binding-energy law is encoded in this repository. Numerical self-consistency of the CTQW does not establish ligand binding or biological efficacy. Some figure artworks are visualization-first and their drawn molecule labels, regression lines or score annotations should be checked against tabular source records before journal release.

## IBM and Rigetti integration

```bash
python -m pip install -r requirements-ibm-optional.txt
python code/ibm_qiskit_bridge.py

python -m pip install -r requirements-rigetti-optional.txt
python code/rigetti_pyquil_bridge.py
```

The two SDK examples were **not executed against physical QPUs**. Authenticated provider access, transpilation, circuit-depth and topology logs, calibrated measurements, shot counts, and job IDs would be needed for an actual hardware benchmark; see `docs/HARDWARE_PORTABILITY.md`.
